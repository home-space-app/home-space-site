Deploy anywhere

Home, VM or cloud — it’s the same two containers.

Home Space ships as an app container and a Postgres database. Wherever Docker runs, Home Space runs.

At home

A mini PC, a NAS or a Raspberry Pi-class box under the desk. Your files never leave the house.

  • Blobs on any disk you choose
  • Runs as its own locked-down user

On a VM

Proxmox, Hyper-V, a homelab cluster or a rented VPS. Put nginx or Cloudflare in front and go.

  • Chunked uploads stay under proxy limits
  • Example nginx config included

In the cloud

Any provider that runs containers. Bring your own identity provider for single sign-on.

  • Secrets from files or Docker secrets
  • Keycloak, Authentik, Auth0, Zitadel…
Quick start

Up and running in a few minutes.

  1. Clone the repository

    Everything you need — Dockerfile and Compose files — lives in one repo.

  2. Set a signing secret and start

    Compose builds the app with the web client and starts Postgres next to it.

  3. Add your first user

    There is no public sign-up: you decide who gets in.

~/home-space
# 1. get the code
$ git clone https://github.com/home-space-app/home-space.git
$ cd home-space

# 2. a 32+ character secret, then start
$ export HOMESPACE_JWT_SECRET=$(head -c 32 /dev/urandom | base64)
$ docker compose up -d --build

# 3. create your account
$ docker compose run --rm app user add me

✓ Home Space is live on http://127.0.0.1:8080
Features

Everything you expect from a file cloud. Nothing you didn’t ask for.

Built to be boring in the best way: your files are safe, findable and in sync.

Version history

Replacing a file keeps the old content as a version. Download or delete any previous one.

Recycle bin

Deleted files wait in the bin with their versions intact, and restore into Lost and Found.

Resumable uploads

Large files go up in chunks and continue where they left off — files up to 10 GiB by default.

Live updates

Changes appear on every open client the moment they happen, over a websocket.

Fast search

Full-text, prefix matching across every folder, with the location of each hit.

Device aware

See which device edited a file, rename devices, and sign one out remotely.

Single sign-on

Plug in any OpenID Connect provider, and limit access to a group like “family”.

Secure by default

Argon2 passwords, short-lived tokens tied to real sessions, logout that takes effect at once.

Smart conflicts

Identical uploads are ignored, folders merge, and you choose to skip or override on clashes.
